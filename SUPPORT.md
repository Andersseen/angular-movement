# Support

Use the right channel so issues stay useful for everyone.

## Questions

Use GitHub Discussions if enabled. If discussions are not enabled, open a documentation issue and
label it as a question.

## Bugs

Open a bug report with:

- Angular version.
- `angular-movement` version.
- Browser and OS.
- A minimal reproduction.
- Expected behavior and actual behavior.

## Feature ideas

Open a feature request and explain the product use case. For motion APIs, examples from Angular
templates are especially helpful.

## Security

Do not open public issues for security reports. See `SECURITY.md`.
