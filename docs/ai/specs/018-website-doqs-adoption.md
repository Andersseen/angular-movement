## Problem / motivation

The site is three things welded together by hand: a marketing page, 12 hand-written Angular
documentation pages with a custom sidebar/quick-find/pager/anchor stack, and an interactive demo
gallery. The documentation infrastructure is ~410 lines of bespoke code that duplicates what Doqs
(our own Markdown documentation library, `@doqs/analog`) now does, with weaker search (title keywords
only), a hand-maintained API reference that can drift, and snippets pasted as strings. The site is
about to be shown to the Angular community, so the product page, docs and demos must read as one
mature product.

## Baseline (measured before any change, `main` @ `4e71e2f`, node-server build)

- Lighthouse 12, mobile emulation, `/`: **performance 68**, accessibility 100, best-practices 100,
  SEO 100; FCP 4.7 s, **LCP 5.4 s**, CLS 0, TBT 20 ms, 632 KiB transferred.
- Static deploy (`wrangler pages deploy dist/analog/public`) contains **only `index.html`** — every
  other route works through Cloudflare Pages' SPA fallback, so deep links are client-rendered and
  unknown URLs answer **200** (the SSR server also answers 200 for `/nope`).
- `og:image` points at `/og-image.png`, which does not exist. No sitemap. `robots.txt` has no sitemap
  line. Footer says "Angular 21" and "© 2025".
- `/demos/*` layout renders its own `<main>` inside the shell's `<main>` (nested landmark).

## Proposed solution

1. **Three areas, one product.** `/` (marketing), `/docs` (Doqs, Markdown source of truth),
   `/demos` (host-owned Angular gallery, unchanged URLs), `/templates` (unchanged).
2. **Doqs 0.11.0** mounted at `/docs`, `landmark: 'host'`, Pagefind search, deterministic Markdown
   plugin, prerender of every route. Authored pages in `src/authoring/docs` resolve (`::source`,
   `::include`, `[[api:…]]`) into `src/content/docs`; API reference generated by `doq-api` from
   `projects/movement/src/public-api.ts` into `src/content/docs/reference` (URL `/docs/reference`
   keeps working as the generated index; symbol pages live below it).
3. **Content.** The 12 Angular page templates become Markdown at the same URLs, rewritten
   task-first; new guides (`/docs/guides/*`) each embed a real playground and link the full demo.
4. **Shared motion examples** (`src/app/motion-examples`): small host-owned wrapper components
   (replay is explicit for one-shot directives) registered with Doqs as `::playground[id]` /
   `::demo[id]`; the full `/demos/*` routes keep `DemoContainer` and gain a doc/API/related strip.
5. **Home** evolves: honest hero from stable APIs with real version metadata, concise narrative,
   curated showcase, code-to-result with live settings.
6. **SEO & delivery**: prerender all routes + a real `404.html`, sitemap generated from the route
   list, branded OG image, canonical URLs, `robots.txt`.
7. **Cleanup**: remove the docs layout, nav model, quick-find, pager, heading-anchors and the
   hand-written reference/API tables once every URL has a Doqs equivalent.
8. **CI**: `doq content check`, `doq-api check`, `doq doctor --build`, Pagefind index in the build.

## Out of scope

- Library runtime, public API, version, tags, npm publish, MCP package.
- Changing Doqs or `node_modules` (findings go to `docs/integrations/doqs-feedback.md`).
- Localization (`/es`, `/uk`): only a follow-up note.
- Global `SmoothScrollService` activation.
