# Spec 020 — 1.5 reliability, repeated interaction and public API contract gate

- **Status:** in-progress
- **Created:** 2026-10-30
- **Last updated:** 2026-10-30
- **Breaks public API:** no
- **Related:** specs 013 (transform ownership), 019; baseline `main` = `ce9b03d`, source 1.4.0

## Problem / motivation

`/demos/drag` tracked the pointer on the first drag and drifted further from it on every later one.
Unit tests were green because they mock the engine and never drag twice; the e2e suite asserted
"the card moved", not "the card moved by exactly the pointer's distance, every time". The same blind
spot applies to every stateful primitive: nothing measured behaviour _after repeated use_.

This milestone adds no feature. It establishes evidence for what already exists.

## Verified defects (baseline `ce9b03d`, real Chromium)

| #   | Defect                                                                                                                                                                                                                                                                                                          | Evidence                                                                                                                          |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| D1  | Drag counts the previous drag's displacement twice: `pointerdown` snapshots the inline transform (already containing it) as the base, then adds `#_x/#_y` again. Press jump = exactly the previous displacement (0 → 46.6 → 93.3 px with a (40, 24) drag; accumulates with same-direction drags).               | `e2e/drag-repeat.spec.ts` free drag, 20 cycles; fails on `ce9b03d`, 0 error after.                                                |
| D2  | A release from an identity base commits the displacement into the individual `translate` property, a second copy the next `transform` write adds to.                                                                                                                                                            | code path trace + snap-point scenario                                                                                             |
| D3  | Pressing during a release animation cancels it first, snapping the card to the stale inline position (jump).                                                                                                                                                                                                    | `pressing during a release animation…` fails on `ce9b03d`.                                                                        |
| D4  | **Cross-engine ownership race.** With a non-empty inline transform the composer put a constant `transform` keyframe into _every_ animation, including opacity-only ones. The tap/hover leave animation therefore pinned `transform` to a stale value over the drag release spring, then committed it on finish. | Probe: computed transform `none` for ~240 ms after release; `keyframe-composer.spec.ts › transform ownership` fails on `ce9b03d`. |
| D5  | `lostpointercapture` was not handled (a drag could outlive its capture).                                                                                                                                                                                                                                        | review; handler added (`onPointerUp` is idempotent).                                                                              |

## Solution

See "Drag displacement is stored once (spec 020)" in `docs/ai/ARCHITECTURE.md`. In short: the drag's
displacement lives in one place and the inline transform is always rewritten from
`origin + displacement + gesture`; a release is a hand-off that is settled to a canonical string;
an interrupting press samples the rendered position first; and no animation without a transform
channel emits `transform`. No public input, output or selector changed.

## Contract gate

`docs/v2/evidence/1.5/contracts.json` lists every export (73: 39 runtime, 34 type) with a status per
behavioural dimension and the executable tests behind each claim.
`scripts/check-contract-inventory.mjs` (CI `library` job, unit-tested in
`scripts/check-contract-inventory.test.mjs`) fails on: an export with no entry, a stability that
disagrees with the API snapshot, a PASS whose cited test or title no longer exists, a
KNOWN_LIMITATION without a justification, and any FAIL. **NOT_TESTED is allowed but never counted as
a pass** and is printed on every run.
