## Problem / motivation

The runtime is broad, but adoption is gated by (a) docs that drift from source (variants example
that silently does nothing, an over-broad per-property-easing limitation, stale status text),
(b) a site that reads as a feature list rather than a demonstration, (c) a code block that renders
hand-written HTML through `bypassSecurityTrustHtml` and has no copy action, (d) no guidance on when
_not_ to use Movement, no migration help for legacy `@angular/animations`, and (e) package
validation that only proves compilation, never browser/SSR/hydration execution.

## Proposed solution (one cohesive minor)

1. **Docs correctness** — fix the confirmed drift items from AUDIT; extend `docs:check` so every
   fenced/embedded snippet's `moveXxx` identifiers and the `[moveVariants]` + `[moveAnimate]`
   anti-pattern are machine-checked.
2. **Safe code block** — `CodeBlock` takes _plain_ source, tokenises it itself and renders tokens
   through Angular template bindings (no `innerHTML`, no sanitizer bypass), with a real copy
   button (raw source, polite live region), language/filename label, keyboard-friendly scroll
   region. Existing hand-highlighted snippets become plain strings.
3. **Docs IA** — grouped, collapsible, keyboard-accessible sidebar with reliable active state,
   mobile drawer, quick-find, previous/next, heading anchors with copyable links. New pages:
   _Choose the right tool_ (CSS vs native `animate.enter/leave` vs Movement vs WAAPI), _Choose an
   API_ (overlap/one-shot-vs-reactive matrix), _Migrate from @angular/animations_ (recipes),
   _Accessibility & troubleshooting_. Existing URLs remain valid.
4. **Home** — new hero with a cohesive interactive showcase (card + state + presence + stagger,
   stable APIs only, no work before hydration, reduced-motion aware), honest positioning section,
   curated use-case showcase linking to demos/docs.
5. **Playground consistency** — `DemoContainer` gets a reduced-motion toggle, accurate copy
   behaviour, stability badge, labelled controls.
6. **Migration assessment** — `projects/movement-migrate` (separate package, TypeScript compiler API +
   `@angular/compiler` template AST, **read-only**, JSON/text report with automatic / partial /
   manual / keep-native classes, file spans and reasons). No rewrite mode.
7. **Packed validation** — extend `scripts/validate-consumer.mjs` so the tarball-built fixture is
   also _executed_: SSR render, hydration with event readiness, browser run (Playwright Chromium),
   reduced-motion and teardown checks, on each supported Angular major; record resolved versions.
8. **Runtime reliability** — regression tests for layout-cancel cleanup, presence rapid toggle,
   destroy-during-animation, SSR/disabled; narrowly scoped fixes only where a test proves a defect.
9. **A11y / perf** — manual keyboard pass, axe via Playwright where available, measured bundle and
   page-load baselines recorded in `docs/v2/VALIDATION.md` evidence section.
10. **Records** — CHANGELOG (Unreleased), STATE, ROADMAP, MIGRATION, READMEs, MCP skill text.

## Out of scope

Any new directive/input/export; 1.4+ orchestration/ownership/router/layout/gesture/scheduler work;
promoting experimental APIs; automatic rewrites; new runtime dependencies; version bump, tag, npm
publish, production deploy; modifying sibling consumer repositories.

## Acceptance criteria

- [ ] `pnpm api:check` unchanged (no snapshot update); no barrel diff.
- [ ] No `bypassSecurityTrustHtml`/`innerHTML` in `src/`.
- [ ] Code block copy puts raw source (no markup) on the clipboard — site unit test + e2e.
- [ ] Docs sidebar: keyboard operable, mobile drawer, active state, prev/next — e2e.
- [ ] `docs:check` fails on the variants/`moveAnimate` anti-pattern and on unknown `move*` identifiers
      in every docs page and README.
- [ ] Migration classifier golden tests incl. negative/dynamic cases; tool writes nothing.
- [ ] Packed fixture executes in a browser and renders/hydrates on a server for each major.
- [ ] Regression tests for each investigated runtime item (pass or documented as deferred).
- [ ] Full gate (CI command list) passes locally; failures/skips reported.
